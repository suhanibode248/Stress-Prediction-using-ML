1. PROJECT DESCRIPTION
========================
NeuroScan is an AI-powered stress detection system that analyzes physiological signals 
to predict stress levels in real-time. The application uses machine learning models 
trained on heart rate, ECG readings, body temperature, facial expressions, and voice 
patterns to detect and measure stress levels.

The system provides users with:
- Real-time stress monitoring via webcam and microphone
- Visual dashboard displaying stress metrics
- Historical data tracking and analysis
- AI-powered insights using Claude Vision API
- Personalized recommendations based on stress patterns

Tech Stack: Flask (Backend), SQLAlchemy (Database), JavaScript (Frontend), 
            Machine Learning (Python scikit-learn/TensorFlow)

3. HOW TO RUN PROJECT
========================
STEP 1: Install Dependencies
$ pip install -r requirements.txt

STEP 2: Set Environment Variables
Create a .env file:
SECRET_KEY=your_secret_key_here
ANTHROPIC_API_KEY=your_claude_api_key
DATABASE_URL=sqlite:///neuroscan.db  # or your PostgreSQL URL

STEP 3: Initialize Database
$ python migrate.py

STEP 4: Run Application
$ python app.py
Visit: http://localhost:5000

STEP 5 (Production): Deploy
Using Gunicorn:
$ gunicorn -w 4 -b 0.0.0.0:5000 app:app

Using Docker/Vercel:
Follow vercel.json configuration for cloud deployment


4. HOW IT WORKS (TECH FLOW)
========================
USER FLOW:
1. User registers/logs in → User credentials stored in database (password hashed with bcrypt)
2. User grants permissions for webcam & microphone
3. Real-time data collection:
   - Facial video → Eye blink detection (blink.js)
   - Heart rate detection from facial color changes
   - Audio stream → Voice emotion analysis (voice.js)
4. Data processing:
   - Physiological signals extracted
   - Features normalized and preprocessed
   - Model.py calculates stress score using ML
5. Claude Vision API analyzes facial expressions:
   - Emotional state classification
   - Stress indicators detection
6. Results displayed on dashboard:
   - Stress level (0-100)
   - Real-time graph
   - Historical trends
7. User receives recommendations based on stress level

TECHNICAL FLOW:
Browser (JavaScript) ↓
 ↓ (WebRTC/getUserMedia)
Capture Webcam + Microphone Data
 ↓
Flask Backend (Python)
 ↓
Data Preprocessing (normalize, extract features)
 ↓
ML Model (Random Forest/Decision Tree)
 ↓
Claude Vision API (facial analysis)
 ↓
Stress Score Calculation
 ↓
Store in SQLAlchemy Database
 ↓
JSON Response → Dashboard Display
 ↓
Real-time Chart Updates (JavaScript)

6. COMMON ISSUES & FIXES
========================
ISSUE 1: "Webcam Permission Denied"
FIX: Allow browser access to webcam in browser settings
     Or use HTTPS in production (http://localhost for development)

ISSUE 2: "Database Connection Error"
FIX: Run 'python migrate.py' to initialize database
     Check DATABASE_URL in .env file
     Ensure PostgreSQL is running (if using PostgreSQL)

ISSUE 3: "Claude API Key Error"
FIX: Set ANTHROPIC_API_KEY in .env file
     Obtain API key from https://console.anthropic.com
     Ensure API key has valid credits

ISSUE 4: "Microphone Not Working"
FIX: Check browser permissions for microphone access
     Test microphone in system settings
     Update browser to latest version

ISSUE 5: "Model File Not Found (emotion_model.hdf5)"
FIX: Ensure models/ folder contains emotion_model.hdf5
     Download pre-trained model or train new one
     Check file path in model.py

ISSUE 6: "Rate Limit Exceeded"
FIX: Configure Redis (UPSTASH_REDIS_URL in .env)
     Adjust rate limiting thresholds in app.py
     Wait before making new requests

ISSUE 7: "Port 5000 Already in Use"
FIX: Change port in app.py: app.run(port=8000)
     Or kill process: lsof -ti:5000 | xargs kill -9

ISSUE 8: "Slow Performance"
FIX: Optimize model loading (cache it)
     Use CDN for static files
     Enable gzip compression
     Use production server (Gunicorn)

8. TIPS FOR BEST RESULTS
========================
FOR ACCURATE STRESS DETECTION:
1. Use in well-lit environment (natural light is best)
2. Position camera 30-60cm from face
3. Keep face centered and clearly visible
4. Minimize head movements during analysis
5. Speak clearly during voice analysis
6. Allow at least 30 seconds of recording
7. Avoid extreme facial expressions initially
8. Run multiple tests for better accuracy
9. Keep the app window fully focused
10. Disable other audio sources (speakers, notifications)

FOR BEST PERFORMANCE:
- Use a stable internet connection
- Close other intensive applications
- Use latest browser version
- Clear browser cache if experiencing issues
- Test microphone/webcam before starting
- Ensure adequate system resources (RAM: 2GB+)
